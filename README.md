# Newsletter Quarks — Octobre 2026

Ce dépôt publie les visuels de la newsletter sur GitHub Pages.

## Fichiers

- `index.html` : newsletter HTML prête à prévisualiser et à intégrer dans un email.
- `assets/` : visuels optimisés et chargés depuis des adresses publiques HTTPS.

## Adresse publique

Après l’activation de GitHub Pages, la prévisualisation sera disponible à :

`https://raphaeldumaslevillain-commits.github.io/quarks-newsletter-octobre-2026/`

Les visuels emploient déjà les adresses définitives GitHub Pages, afin qu’ils s’affichent aussi une fois le HTML intégré dans un email.

## Avant l’envoi

1. Remplacer `{{unsubscribe_url}}` par le lien de désinscription choisi.
2. Mettre à jour les liens de navigation et les liens de profil lorsqu’ils seront validés.
3. Faire un envoi test vers une adresse Gmail et une adresse Outlook.

Le HTML ne contient aucun JavaScript. Les éléments sont structurés en tableaux et les styles critiques sont intégrés pour une compatibilité email étendue.
